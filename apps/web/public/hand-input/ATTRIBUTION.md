# Hand input model

`hand_landmarker.task` is Google's MediaPipe Hand Landmarker float16 model bundle,
version 1, downloaded without modification.

- Source: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
- Documentation and model card: https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker#models
- SHA-256: `fbc2a30080c3c557093b5ddfc334698132eb341044ccee322ccf8bcf3607cde1`

MediaPipe Tasks Vision is provided by Google under Apache-2.0. Its JavaScript and
WASM runtime assets come from the pinned `@mediapipe/tasks-vision` npm package.

do not apply to these files.
